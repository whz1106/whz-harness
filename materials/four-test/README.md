# four-test-v1 项目入口

当前多模态压测项目在独立私有仓库 `whz1106/four-test-v1`；`whz1106/four-test` 是旧仓库。本 harness 不复制项目代码、模型、数据、镜像或操作细节。

```bash
gh repo clone whz1106/four-test-v1 ~/four-test-v1
```

工作时以该项目**当前版本**的 `AGENTS.md`、`README.md` 和对应脚本为准。若部署在 `agc64f`，先读本仓库 `machines/AGENTS.md`、`machines/RULES.md`、`machines/agc64f.md` 并核对现场状态。这里保存的项目规则历史快照仅供追溯，不作为当前运行依据。
