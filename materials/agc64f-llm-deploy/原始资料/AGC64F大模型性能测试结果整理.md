# AGC64F 大模型性能测试结果整理

## 1. 整理范围

本文从《AGC64F智算服务器-测试说明(1)》的“4.4 模型性能测试”章节中，整理以下 4 个大语言模型的部署配置、测试结论和完整性能数据：

- MiniMax-M2.5
- Qwen3.5-122B-A10B
- Qwen3.6-35B-A3B
- DeepSeek-R1-Distill-Llama-70B

> 说明：各模型使用的精度、物理卡数及输入输出长度并不完全一致，横向比较时应结合具体测试条件，不能只比较单一峰值。

## 2. 测试指标说明

| 指标 | 含义 | 趋势 |
|---|---|---|
| 输出吞吐效率 | 全部并发请求合计的输出 Token 生成速率 | 越高越好 |
| 总吞吐效率 | 输入与输出 Token 合计的处理速率 | 越高越好 |
| 首 Token 延时 | 从请求发出到收到第一个 Token 的时间，即 TTFT | 越低越好 |
| TPOT | 输出阶段平均生成一个 Token 的耗时 | 越低越好 |
| 平均每并发输出速度 | 输出吞吐效率除以并发数 | 越高越好 |

## 4. 关键结果汇总

以下是每个模型在本次全部测试记录中的指标极值。各极值可能来自不同并发数及不同输入输出长度，仅用于快速查看测试范围内的最好记录。

| 模型 | 峰值输出吞吐<br>tokens/s | 峰值总吞吐<br>tokens/s | 最低首 Token 延时<br>ms | 最低 TPOT<br>ms | 最高平均每并发输出<br>tokens/s |
|---|---:|---:|---:|---:|---:|
| MiniMax-M2.5 | 2,337.91 | 2,630.15 | 110.66 | 11.39 | 87.57 |
| Qwen3.5-122B-A10B | 12,156.44 | 18,234.65 | 55.82 | 8.91 | 108.86 |
| Qwen3.6-35B-A3B | 18,268.24 | 20,551.77 | 42.05 | 7.48 | 132.14 |
| DeepSeek-R1-Distill-Llama-70B | 3,679.15 | 5,321.17 | 50.24 | 25.40 | 39.07 |

### 4.1 数据现象

- Qwen3.6-35B-A3B 在本次记录中取得最高输出吞吐和最高总吞吐，分别为 18,268.24 tokens/s 和 20,551.77 tokens/s。
- Qwen3.6-35B-A3B 同时取得最低首 Token 延时 42.05 ms、最低 TPOT 7.48 ms，以及最高平均每并发输出速度 132.14 tokens/s。
- Qwen3.5-122B-A10B 在 768 并发、输入 64 tokens、输出 128 tokens 时，总吞吐达到 18,234.65 tokens/s；但在较长输入输出场景下，高并发会明显推高首 Token 延时。
- MiniMax-M2.5 的峰值输出吞吐为 2,337.91 tokens/s；并发由 1 提升至 128 时，总吞吐提升，但平均每并发输出速度下降。
- DeepSeek-R1-Distill-Llama-70B 使用 FP16 精度，在本次记录中的峰值总吞吐为 5,321.17 tokens/s；其 TPOT 整体高于另外三个模型。

> 上述内容是对表格数据的直接归纳。由于模型规模、精度、卡数及测试负载不同，不代表同等条件下的严格性能排名。

## 9. 总体测试结论

4 个大语言模型均完成部署和 `vllm bench serve` 基准测试，测试结果全部判定为“符合”。测试期间均记录为：

- 基准测试正常运行完毕；
- `dmesg` 无异常；
- GPU 温度正常，未出现降频。

从本次记录看，Qwen3.6-35B-A3B 在 32 张物理卡、FP8 精度下表现出最高的峰值吞吐与最低的延时指标；Qwen3.5-122B-A10B 在 64 张物理卡、INT4 精度下也达到较高的并发吞吐。MiniMax-M2.5 和 DeepSeek-R1-Distill-Llama-70B 的测试配置、精度及负载与前两者不同，因此这些结果适合用于记录各模型在当前部署方案下的能力，不宜直接视为严格的同条件排名。
